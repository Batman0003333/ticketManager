# ticketManager     https://ticketmanager-1-q2u5.onrender.com---------------------------------


A ticket management application for organizing and tracking tickets efficiently.



## Features

- Create, read, update, and delete tickets
- Organize tickets by status and priority
- User-friendly interface
- Real-time updates

## Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js / Express.js
- Database: MongoDB
- Deployment: Render

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- MongoDB
